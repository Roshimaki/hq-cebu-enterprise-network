Network Management & SNMP Monitoring Implementation
1. Overview & VerificationTo establish administrative oversight and query device telemetry, Simple Network Management Protocol (SNMP) community strings were configured across the network infrastructure. SNMP agent responsiveness was validated using the end-host MIB Browser tool.SNMP Read-Only (RO) Community String: Configured to grant read-only polling access for network monitoring queries.Tested OID: .1.3.6.1.2.1.1.5.0 (sysName)
2. Test Results & Practical ObservationsRouter Implementation (HQ-CME1):Result: SUCCESS   Observation: The router responded to the MIB Browser GetRequest query instantly, successfully returning its system hostname (HQ-CME1) over the network.   Multilayer & Access Switch Implementation (HQ-DIST-SWT1 / Access Switches):Result: TIMEOUT / NO RESPONSE   Observation: While the switches successfully accepted the SNMP community CLI configurations (snmp-server community <word> ro), MIB Browser queries targeted at the switch SVIs resulted in request timeouts.   Documentation Note: Based on empirical testing within this simulation environment, SNMP polling via MIB Browser functioned reliably on the Cisco router platform. The failure to poll multilayer switches is documented as a simulator/platform-specific constraint within Cisco Packet Tracer rather than a structural layer configuration flaw.
